 # 8-bit ALU in Verilog

An 8-bit Arithmetic Logic Unit with a self-checking testbench.

## Operations
ADD, SUB, AND, OR, XOR, NOT, Compare (greater than)

## Outputs
result (8-bit), carry flag, zero flag

## Files
- alu.v: design
- tb.v: self-checking testbench
- waveform.png: simulation waveform
- log.png: test log (ALL TESTS PASSED)
